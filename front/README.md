# IbnSina — frontend

Vite + React + TypeScript. Устройство, команды и правила — в [AGENTS.md](AGENTS.md).

```bash
npm install
npm run dev        # http://localhost:5173, /api -> http://localhost:8000
```

Бэкенд должен быть запущен (см. `../back/README.md`). Логины для разработки
создаёт `back/seed.py`.
